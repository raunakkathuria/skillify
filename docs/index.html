A table of contents for your AI skills

Scan your skills folder. Get a searchable index, knowledge graph, and analytics report. Agents find the right skill instantly — not by reading everything.

Visual Representation

Keywords from your index pointing to skills — like a book's table of contents pointing to chapters.

Features

📖
Smart Index

Generates skills-index.json — a lightweight table of contents AI agents load instead of all your skill files

🔍
Instant Search

Search by keyword from CLI or programmatically. Find the right skill in milliseconds.

🎨
Visual Graph

Interactive HTML knowledge graph + animated SVG showing how skills connect

🔄
CI/CD Ready

--check exits 1 when stale, --diff shows changes, --json-output for automation

🔌
One-Command Setup

skillify install claude/codex/cursor/kiro — wires into your AI tool automatically

📊
Analytics Report

Clusters, hubs, keyword frequency, isolated skills — understand your skill landscape

How It Works

1
Scan

Point skillify at your skills folder or GitHub repo

2
Index

Get a structured JSON index + knowledge graph + report

3
Load

Agents search the index and load only matching skills on demand

Get Started

pip install skillify
skillify scan ./my-skills/
skillify install claude

Or install from source:

git clone https://github.com/raunakkathuria/skillify.git
cd skillify && pip install .

What You Get

skillify-out/
├── graph.html          ← interactive visualization
├── graph.svg           ← animated SVG for docs
├── graph.json          ← raw graph data
├── skills-index.json   ← THE INDEX (what agents consume)
├── SKILLS_INDEX.md     ← human-readable table of contents
└── SKILLIFY_REPORT.md  ← analytics report
